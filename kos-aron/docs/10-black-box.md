## Mengulang pengujian

Dari akar repositori, jalankan kedua perintah berikut dengan Python 3. Skrip memerlukan PHP CLI dengan PDO MySQL, konfigurasi koneksi lokal yang dapat membuat database uji, serta Chrome untuk cetak PDF. Lokasi Chrome dapat diberikan melalui variabel lingkungan `CHROME_BIN`.

```console
python -B scripts/uji-tahap-10.py
python -B scripts/uji-tahap-09.py
```

Skrip Tahap 10 menguji BB01–BB16 beserta BB10a–BB10c. Skrip Tahap 9 menyediakan BB17–BB23. Keduanya menggunakan salinan aplikasi dalam direktori sementara, nama database acak, server PHP loopback dan password yang dibuat untuk satu eksekusi. Konfigurasi MySQL setiap salinan menunjuk ke database uji yang namanya diperiksa sebelum pengisian. Skrip menghapus database uji setelah eksekusi dan menghentikan server. Kedua proses selesai dengan kode 0.
